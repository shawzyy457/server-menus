# EXE server menus

Definições dos menus da rede EXE para Minecraft 1.8.8.

- `global/` contém os menus partilhados por todos os servidores.
- Um diretório com o ID de um servidor pode substituir ou acrescentar menus apenas nesse servidor.
- `dist/` é gerado por `node build-menus.mjs` e consumido pela Platform API.

Os nomes dentro de cada bundle são os caminhos relativos sem a extensão `.json`.
